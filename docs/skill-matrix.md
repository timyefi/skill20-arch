## 手册如何体现 Skill 2.0

- 每本手册把中间件拆成「数据源 → 取数 → 知识 → 计算 → 输出」五层，逐层给出 **IN/OUT/DEP 接口契约**与独立调用示例——「教用户用整体」变成「展示每个模块的独立价值」。
- 知识层的阈值与规则以**判断框架**呈现（维度 + 方向 + 结构），配套市场回验方法论（取数 → 分位数 → 标注事件窗口 → 比较中枢漂移 → 更新阈值），鼓励结合自身研究体系定期校准。
- 面向集成者的架构手册与面向使用者的介绍手册分开，口径不同、维护独立。
